HOW TO UPDATE YOUR LIVE GITHUB PAGES WEBSITE FROM AN ANDROID PHONE:
1. Open your repository:
   https://github.com/brothersublimation95-eng/Brothersublimation-and-hosiery-
2. Upload the new index.html file and the entire images folder (with all files inside).
   On GitHub, use Add file > Upload files. If mobile upload does not let you upload a folder,
   open the images folder on your phone and select all six image files, then upload them together.
3. Commit changes.
4. Wait a few minutes, then open:
   https://brothersublimation95-eng.github.io/Brothersublimation-and-hosiery-/

IMPORTANT:
- Keep the filenames exactly as they are in the images folder.
- Do not upload only index.html: the images folder is also required.
- If you already have other files in your repository, do not delete them unless you know they are not needed.
- This ZIP contains the website source and image files; it does not automatically change your live GitHub site.
- Some uploaded images are presentation/mockup graphics. Replace them with real product photographs when possible.
