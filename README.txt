FREE HOSTING WITH GITHUB PAGES
1. On your phone or computer, open https://github.com/ and create/sign in to an account.
2. Create a new PUBLIC repository. A name such as brother-sublimation-site works.
3. Upload the index.html file from this ZIP to the repository's top level.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for publishing, then open the website URL shown on the Pages screen. It often looks like https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
7. Keep the repository public for this free GitHub Pages setup. Do not put passwords, private buyer details or confidential information in the repository.
